# Проверки перед публикацией Gym 45

Пользователь тренируется по приложению каждый день. Правило: **ни одно обновление не публикуется, пока не пройдёт проверка сохранности данных.**

```bash
git show main:index.html > /tmp/old.html          # то, что сейчас у пользователя
python3 tests/upgrade_check.py /tmp/old.html index.html
```

Тест в старой версии создаёт реальные данные: программу GVT с весами, завершённую тренировку, незавершённую тренировку (часть подходов, изменённый вес), историю, дневник питания, кроссфит-результат, «Сотку». Затем открывает новую версию на том же адресе и проверяет:

- все данные старой версии на месте байт в байт, новые ключи только служебные;
- незавершённая тренировка продолжается с тех же подходов и весов и завершается;
- история пополняется, старые записи не меняются;
- автоснимок делается при запуске, откат к снимку возвращает данные;
- копия в файл содержит все разделы.

Правила для изменений кода:

- не переименовывать и не удалять ключи `gym45_*` и поля в сохранённых записях; новые поля — только необязательные;
- миграции — только добавляющие, старые данные не перезаписывать;
- автоснимок (`gym45_safety_v1`) выполняется первым в скрипте, до любого кода приложения — не переносить его ниже.
